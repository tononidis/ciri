## Consistency
Make sure your code is consistent with the existing codebase. Follow the same naming conventions, coding style, and design patterns. This will help maintain the readability and maintainability of the code.

## Formatting
Keep the code style consistent with the existing codebase. Use projects clang-format file to format your code before submitting a pull request.

## Pull Requests
Fork the repository and create your branch from `main`. 

When you are ready to submit your changes, create a pull request. Make sure to provide a clear description of the changes.
